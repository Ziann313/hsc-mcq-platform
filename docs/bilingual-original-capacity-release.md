# Bilingual Original Question Capacity Release

## Scope

This release expands MCQ GURU’s Bangla-language practice capacity with **twelve independently authored original HSC questions**. The added items are Bangla counterparts covering the same curriculum-aligned concepts already available in English across Physics 1st Paper, Chemistry 1st Paper, Biology 2nd Paper, and Higher Mathematics 2nd Paper.

## Release inventory

| Subject | New Bangla originals | Release coverage |
| --- | ---: | --- |
| Physics 1st Paper | 3 | Significant figures, dimensions of force, kinetic energy |
| Chemistry 1st Paper | 3 | Molar mass, amount of substance, pH |
| Biology 2nd Paper | 3 | DNA base pairing, mitosis, mitochondrial ATP production |
| Higher Mathematics 2nd Paper | 3 | Derivative, indefinite integral, determinant |
| **Total** | **12** | HSC board-standard original practice |

Each item was created through the established reviewer-governed release path. The process created the record, validated its academic chain, registered active HSC curriculum/pattern-context source evidence, verified exactly one answer among four options, reviewed the explanation and original-content declaration, approved the question intelligence record, and published an immutable version.

## Content boundary

The questions are **not translations or copies of official textbooks, board papers, admission papers, or historical questions**. They are original educational practice items. The active source evidence establishes curriculum and assessment context; it does not authorize reproduction of protected source text.

## Availability outcome

The release increases Bangla capacity in each of the four selected subjects from four to seven active, source-linked published items. The original English HSC and admission capacity remains unchanged. Language filters keep Bangla and English item sets distinct, so students receive the selected language only when an immutable practice attempt is assembled by the server.

## Validation

The audited release script reported **12 created and 12 published** items, with the prior 42 reviewed capacity items skipped idempotently. Database checks confirmed active source links, approved intelligence records for the new items, four options per checked question, and one correct option per question. The complete suite passed with **93 tests** and one intentional OAuth skip; the production build passed. Mobile Practice and Admission Preparation screenshots remained responsive after the capacity update.
